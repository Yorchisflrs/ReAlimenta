# 2. Modelo de desarrollo propuesto

> Documento histórico de planificación del prototipo. Para los incrementos implementados y pruebas del MVP, consulte PROGRESO_REAlimenta_2.md y Modulos_Funcionales_REAlimenta.md.

**Proyecto:** REAlimenta  
**Modelo:** incremental e iterativo con enfoque ágil

## Fundamentación

REAlimenta reúne decisiones de varios actores y requisitos alimentarios todavía pendientes de consulta especializada. Un modelo incremental permite entregar partes delimitadas, revisarlas con donantes, organizaciones y docentes, y ajustar el flujo antes de ampliar el alcance. La iteración evita tratar las primeras pantallas o reglas como definitivas. El enfoque ágil se entiende aquí como revisión frecuente y adaptación basada en evidencias; no se afirma aplicar Scrum completo ni ceremonias no definidas.

## Incrementos previstos

| Incremento | Contenido y resultado esperado |
| --- | --- |
| 1. Análisis y prototipo | Identificación de actores, flujo, estados, requisitos preliminares, interfaz navegable y documentación inicial. **Estado actual.** |
| 2. Usuarios y organizaciones | Gestión real de cuentas y perfiles, permisos y verificación inicial. |
| 3. Donaciones | Persistencia y validaciones de publicación, conservación, envase y disponibilidad. |
| 4. Solicitudes | Solicitudes por donación, evaluación, selección única y notificación de resultados. |
| 5. Seguimiento, recojos y entregas | Hitos logísticos, responsables, cadena de custodia, confirmación de entrega y recepción. |
| 6. Notificaciones y alertas | Eventos vinculados a referencias, preferencias y reglas de aviso. |
| 7. Administración y reportes | Gestión y supervisión por rol, incidencias, verificaciones e indicadores. |
| 8. Pruebas y validación | Pruebas funcionales, de accesibilidad, seguridad y desempeño; revisión con actores y especialistas. |

## Ciclo de cada incremento

En cada incremento se refinan requisitos, se diseña el comportamiento, se implementa una parte verificable, se prueba y se recoge retroalimentación. Las observaciones alimentan la siguiente iteración y pueden exigir corregir incrementos anteriores. Antes de implementar reglas operativas de alimentos deben validarse los criterios con profesionales de Nutrición e Ingeniería Agroindustrial.

## Estado del entregable actual

El proyecto se encuentra en el **incremento 1**. Sus formularios y botones simulan interacciones en el navegador sin persistencia, autenticación ni integraciones. La documentación de arquitectura y entidades describe intenciones futuras, no componentes ya construidos.
